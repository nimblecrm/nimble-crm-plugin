# Get help with Nimble

1. Call `search_knowledge_base` with the user's question in plain words. Rephrase and search again when the first
   results do not address it.
2. Answer from the returned articles only, and link the articles you used.
3. When `no_relevant_articles` is true or the articles do not cover the question, say so and point the user to Nimble
   support at support.nimble.com instead of guessing how the product works.

When the question is about the user's records, such as their contacts, deals, or emails, use the other Nimble skills
instead.
